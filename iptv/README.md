# TVBox 直播源（自建精选 + 日更两层）

生成 2026-09-25 10:18。本目录的 `live.m3u` / `live.txt` / `live.json` 已替换 2026-09-24 那份 13 台精选版（旧版仍在 git 历史里）。

## 一、判据：什么才算"可用"

一条 URL 必须同时通过四道关，且**三轮独立复验**都在场：

1. **裸直连**：只带浏览器 UA，**不发 Referer、不发 Cookie、不补任何 token**。发不出 Referer 就播不出来的，一律剔除——盒子做不到。
2. **清单合法**：`#EXTM3U` 可解析；master 清单要能选出 variant；无 `#EXT-X-ENDLIST`、无 `PLAYLIST-TYPE:VOD`、窗口总时长 ≤ 30 分钟。
3. **真分片**：实际下载中间/末尾分片，校验 MPEG-TS 魔术字节（`0x47` 同步，支持 188/192/204 三种步长）或 fMP4 `ftyp`，并据此算出真实码率。
4. **会滚动**：间隔 6 秒二次拉清单，`MEDIA-SEQUENCE` 或末片必须变化。抓出 **22 条冻帧/循环假直播**——只看第 2、3 关是发现不了的。

外加两条硬排除：**带当日会话签名**（`msisdn=` / `SecurityKey=` / `encrypt=` / `wsSecret=` / `timestamp=20…`）的一律不进静态文件，两天必死；URL 路径里出现 **7 天前的 `/YYYY/MM/DD/` 上传日期**（快手/抖音录播被当直播卖）直接踢掉。上一版翻车的"广东卫视"就是这种：`txmov2.a.kwimgs.com/upic/2023-01-26/…`。

- **★稳定精选**：本目录 `live.m3u`，27 台，全部无签名、三轮验活、多线路（同名多行即备线，单主机最多 4 条，避免一个中转挂了带走 10 个台）。这一层是我自己的资产，坏了改文件即可。
- **日更层**：`live.json` / `../mirror/tang_live.json` 里另外挂 3 个**上游每天重新签名的清单**（Supprise0901 每日约 02:05、hujingguang 每日约 02:11、vbskycn 每日约 22:23，按 commit 时间核实）。咪咕持牌线路那批央视全套画质最好但带 `msisdn`+`encrypt` 当日签名，**写死进文件必过期**，所以只做在线引用，让上游 CI 每天替我们换新。

这样 CCTV-1/6/16、江苏/天津/山东/安徽/湖北 等稳定层没有的台，由日更层补齐；日更层挂了，稳定层还在。

## 六、复现 / 维护

工具链在本会话工作区，纯 Python 标准库，无第三方依赖：

- `harvest.py` — 拉 8 个上游清单，抽央视/卫视 URL，去重
- `verify.py <in> <out> [tag] [advance]` — 四道关验活；全局令牌桶限速（0.09s/请求）+ 单主机并发 ≤2，避开"批量并发假 403"这个坑
- `gen.py --r1 --r2 --hosts host_class.json` — 域名可信度打分 + 单主机限额多样化 + 输出三种格式
- `host_class.json` — 台网/持牌/裸IP/动态域名/短视频CDN 分类表（按本轮真实出现的域名写）

建议把 `verify.py` 并进每日 21:30 的 `D:\软件	vbox订阅自检efresh_mirrors.py`，输出"掉线台账"，掉超过 5 台就重跑 `gen.py`。这属于维护层改动，等你点头再动那个脚本。
